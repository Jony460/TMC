THE MEDIA CHAPERONE WEBSITE

1. Open the tmc_media_chaperone folder in VS Code.
2. Open index.html to edit the website.
3. The CSS and JavaScript are included in index.html, so you can start with one file.
4. Use Live Server in VS Code to preview changes in your browser.
5. The contact form opens WhatsApp using the phone number shown on the site; it does not send email or save submissions to a database.
6. Before publishing, confirm the WhatsApp number, Instagram handle, service list and all business claims.
7. For best maintenance, consider moving the embedded logo image into an assets folder later.
